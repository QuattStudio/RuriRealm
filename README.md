# Ruri Realm

**Ruri Realm** is a voxel sandbox game focused on freedom, exploration, building, and deep world simulation.

The goal is to create a world where players can build and survive like a traditional voxel sandbox, while allowing much more complex interactions between the environment, machines, fluids, physics, and the world itself.

# For Programmers

Ruri Realm is being built **from scratch in C** with a strong focus on performance, low-level control, and a minimal amount of unnecessary abstraction.

## Architecture

### Graphics

<!-- Ruri Realm uses **Vulkan** as its graphics API. -->

There is no OpenGL rendering backend.

The renderer is designed around explicit Vulkan resource management and is intended to efficiently handle the large amount of geometry generated by a voxel world.

### Platform Layer

Ruri uses a **highly customized GLFW-based platform layer**.

The original GLFW architecture supports many different use cases and graphics APIs. Ruri removes functionality that is unnecessary for the game and specializes the remaining platform code around its requirements.

The platform layer is responsible for things such as:

* Window creation and management
* Keyboard input
* Mouse input
* Raw mouse input
* Gamepad/controller input
* Joystick input
* OS event processing
* Monitor/display information
* Vulkan surface creation

Ruri is designed around a single primary game window, allowing unnecessary multi-window infrastructure to be eliminated.

### Design Philosophy

The project prioritizes:

* Low runtime overhead
* Explicit resource management
* Minimal unnecessary abstraction
* Data-oriented systems where appropriate
* Efficient CPU/GPU communication
* Large-world scalability
* Deterministic and predictable systems where practical
* Platform-specific optimization when it provides a meaningful benefit

The project is intentionally built close to the operating system and graphics API rather than relying on a large general-purpose game engine.

## World Simulation

The world is intended to contain systems that interact with each other rather than existing as isolated game mechanics.

For example:

```text
World
 ├── Terrain
 ├── Fluids
 ├── Physics
 ├── Machines
 ├── Destruction
 ├── Aerodynamics
 ├── Vehicles
 └── Environment
```

These systems are intended to operate on the same underlying world rather than using completely separate representations.

## Status

Ruri Realm is currently in active development.

The project is being developed incrementally, starting with the platform layer and Vulkan renderer before progressively adding the voxel world and simulation systems.

More systems will be documented as they become implemented.
